EL CAPRICHO CLUB — SETUP SUPABASE

Aprire Supabase > SQL Editor e usare il file Club/supabase-setup.sql. Eseguire il codice una sola volta con Run. Non usare la Secret Key nel browser.

Dopo il setup, l'app può registrare nuovi clienti nel database e leggere il saldo punti tramite un token cliente memorizzato sul dispositivo.
